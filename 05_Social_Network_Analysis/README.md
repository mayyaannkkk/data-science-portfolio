# Social Network Analysis with NetworkX

**Course:** DSA 506 Visual Analytics and Communications
**Environment:** VS Code + Python

## Overview
Analyzed a 100-user social network to identify influencers, compute shortest paths, and detect communities.

## Analyses
| Question | Method |
|----------|--------|
| Top influencers | Degree centrality, betweenness centrality |
| Shortest paths | NetworkX shortest_path |
| Communities | Louvain algorithm |
| Sector breakdown | Treemap visualization (Plotly) |

## Files
| File | Description |
|------|-------------|
| `social_network_analysis.ipynb` | Full notebook |
| `social_network1.csv` | Edge-list network dataset |

## Tech Stack
Python, NetworkX, Plotly, Matplotlib, community (python-louvain), Pandas
